# Jellyfin Midnight Blue 3.1

Midnight Blue is a deep navy theme for Jellyfin Web with blue accents, rounded cards, and a translucent header. Version 3.1 styles the movie details ribbon (`.detailRibbon`) and keeps the header navy when you scroll.

## Installation

1. Open [midnight-blue.css](https://raw.githubusercontent.com/Jandoer0/jellyfin-midnight-blue/main/midnight-blue.css) and copy its full contents.
2. In Jellyfin Web, go to **Dashboard → Branding** for a server-wide theme or **Settings → Display** to apply it to your own profile.
3. Paste the stylesheet into **Custom CSS**, save, and reload Jellyfin Web. If you already use custom CSS, keep a copy before replacing it.
4. To remove the theme, delete the pasted CSS or restore your previous stylesheet, then save and reload.

Custom CSS applies to clients that use Jellyfin Web. See [Jellyfin's CSS customization guide](https://jellyfin.org/docs/general/clients/css-customization/).
